17. CURRENT OBSTACLES / RISKS
==================================================

1. Language mismatch
Many attractive infrastructure / platform roles are Go, Python, Java, or TypeScript-first.

Mitigation:
- Target roles that explicitly accept strong engineers from other languages
- Emphasize backend fundamentals, data systems, reliability, and production ownership
- Be transparent about language transition

2. Dedicated SRE / DBA requirements
Some database reliability / platform roles require 5-7+ years specifically in DBA / SRE.

Mitigation:
- Position as senior backend engineer with strong real production reliability and database performance experience
- Do not claim dedicated DBA history

3. Data engineering stack gap
Some roles require Spark, Databricks, Delta Lake, deep Python.

Mitigation:
- Apply only when they value transferable systems / SQL / cloud knowledge
- Be transparent about the gap
- Use real AWS teaching / presentation experience accurately

4. Frontend-heavy roles
Many "full-stack" roles are actually React-first.

Mitigation:
- Prefer backend-leaning full-stack
- Avoid roles where React is clearly the main specialization

5. AI specialization inflation
Many current roles expect years of agentic AI / RAG / ML platform experience.

Mitigation:
- Emphasize daily Claude Code use and reusable AI engineering workflows
- Do not present this as equivalent to production AI platform ownership

6. Consultancy / intermediary risk
Many technically good PHP jobs are through agencies / outsourcing companies.

Mitigation:
- Prefer product companies
- Consider consultancy selectively when technical fit is exceptional
- Always flag client-project risk

7. Remote ambiguity
Some jobs say remote but later ask for office attendance.

Mitigation:
- Check application form and official location wording
- Treat hybrid requirement as material concern

8. Culture mismatch
Some companies explicitly reward extreme pace / long hours / constant shipping.

Mitigation:
- Scan values and application wording carefully
- Prefer reliability, maintainability, and long-term quality over speed-at-all-costs

9. Stale job pages
Several roles remained indexed after closing.

Mitigation:
- Always verify official careers page and working apply endpoint
